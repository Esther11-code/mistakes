# MentorVerse 🎯

A **goal-oriented mentorship platform** connecting Mentors and Mentees through structured, developmental relationships.

## 📱 About

MentorVerse is a cross-platform mobile app that makes mentorship **goal-oriented**, not just casual networking. Mentees set development goals, track progress with visual indicators, and receive real-time feedback from their mentors.

## ✨ Features

| Feature | Description |
| --------- | ------------- |
| 🔐 **Authentication** | Secure login/signup with email |
| 👥 **Dual Roles** | Sign up as Mentor, Mentee, or Both |
| 🔍 **Mentor Discovery** | Search, filter, and bookmark mentors |
| 🤝 **Connection Workflow** | Send/Accept mentorship requests |
| 🎯 **Goal Tracking** | Create goals with deadlines & progress bars |
| 💬 **In-App Messaging** | Real-time chat with attachments |
| 📊 **Dashboards** | Personalized views for each role |
| ⭐ **Reviews & Ratings** | Rate your mentorship experience |

## 🚀 Getting Started

### Prerequisites

- Flutter SDK 3.9+
- Dart SDK
- Android Studio / VS Code

### Installation

```bash
# Clone the repository
git clone https://github.com/Esther11-code/mistakes.git

# Navigate to directory
cd mistakes

# Install dependencies
flutter pub get

# Run the app
flutter run
```

## 📂 Project Structure

``` directory
lib/
├── config/          # Routing & configuration
├── constants/       # Colors, utilities
├── features/
│   ├── Authentication/   # Login/Signup
│   ├── Onboarding/       # Welcome flow
│   ├── Home/             # Mentor + Mentee dashboards
│   ├── Chat/             # Messaging system
│   ├── Goal/             # Goal management
│   ├── Profile/          # User profiles
│   ├── Dashboard/        # Analytics
│   ├── Bookmark/         # Saved mentors
│   ├── Notification/     # Alerts
│   └── Rating&Reviews/   # Feedback
└── global widgets/  # Reusable UI components
```
